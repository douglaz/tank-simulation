# Implementation Response (Iteration 1)

## Changes Made
1. **Fixed shared DO/alkalinity budget in nitrification limiters** — Rewrote the nitrification section of `nitrogen_cycle.rs` to maintain running `do_budget` and `alk_budget` variables that are decremented after each guild's conversion (AOB, then comammox, then NOB). Each guild's realized rate is now capped by the remaining shared DO and alkalinity budgets before substrate is converted, preventing combined oxidation from exceeding available resources. The Monod DO factor for each subsequent guild also uses the remaining `do_budget` rather than the pre-consumption pool.

2. **Added dirty-filter slowdown factor** — `compute_env_factors` now computes a `dirty_filter_factor` from `filter_state.clogging_index`: `(1.0 - 0.8 * clogging_index).clamp(0.2, 1.0)`. This factor is multiplied with `maturity_factor` as a combined environmental modifier (`combined_env`) applied to all three nitrifier guilds' Monod rates. A `clogging_index` of 0 (clean) gives factor 1.0; a fully clogged filter gives 0.2.

3. **Tightened `comammox_vmax_fraction` validation** — `ProcessParamsPreset::validate()` in `presets.rs` now rejects `comammox_vmax_fraction > 1.0` with a descriptive error, enforcing the spec requirement that comammox uses a lower vmax than the AOB TAN→nitrite path.

4. **Added 3 new regression tests** in `cycling.rs`:
   - `limiter_shared_do_budget`: Verifies that with a tiny DO pool (2 mg) and large nitrifier biomass, combined AOB+comammox O2 consumption never exceeds the starting budget.
   - `limiter_low_alkalinity_caps_nitrification`: Verifies that near-zero alkalinity (0.15 meq) caps total nitrification to the chemically supported fraction, keeping alkalinity non-negative.
   - `dirty_filter_slows_nitrification`: Verifies that a clogged filter (`clogging_index: 0.9`) leaves higher residual TAN after 24h compared to a clean filter (`clogging_index: 0.0`).

5. **Enabled `float_roundtrip` feature for serde_json** — The algorithmic changes produced f64 values that hit a JSON float parsing precision edge case (1-ULP errors in save/load roundtrip). Enabled `serde_json = { version = "1", features = ["float_roundtrip"] }` in `tank_core/Cargo.toml` to guarantee exact f64 roundtripping.
