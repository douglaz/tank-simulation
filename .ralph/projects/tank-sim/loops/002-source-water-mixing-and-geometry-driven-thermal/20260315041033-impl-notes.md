# Implementation Notes

## Decisions Made
- Source water presets now carry 16 explicit per-liter chemistry fields (TAN, nitrite, nitrate, phosphate, DIC, DOC, DON, alkalinity, Ca, Mg, Na, K, HCO3, Cl, SO4, temperature), replacing the old GH/KH/TDS/pH summary fields entirely. The old summary values are documented in provenance notes for reference.
- `ro_like` is defined as pure zero across all dissolved species, making it the exact zero-nutrient reference for the 50% mass-balance regression test (50% ± 0.0%).
- Ion concentrations for `soft_acidic`, `moderate`, and `hard_shrimp` were back-calculated from their original GH/KH/TDS values to maintain internal consistency with the display formulas.
- `SourceWaterProfile` (runtime) lives in `tank_core::types::source_water` with no dependency on `tank_data`. Conversion from preset to profile happens in `tank_scenarios`.
- `ProcessParams` (runtime) in `tank_core::types::process` carries heat-transfer coefficients (`k_surface_w_per_m2_k = 10.0`, `k_wall_w_per_m2_k = 5.0`) alongside the existing chemistry rate parameters.
- `TankState` stores a `BTreeMap<String, SourceWaterProfile>` catalog and `ProcessParams` directly, ensuring deterministic save/load serialization order.
- Schema version bumped from 1 to 2 since new required fields in `TankState` break backward compatibility with v1 save files.
- `PlantGuild` enum now derives `Copy` in addition to `Clone` since it's a simple fieldless enum.
- `HeaterState` gains `last_output_w` (serde-defaulted to 0.0 for partial backward compat) to expose heater runtime state.
- Water change pre-validation scans the entire action queue before processing any actions, ensuring the partial-failure invariant: unknown source profile → typed error with zero state mutation.
- The `0%` water change short-circuits as a no-op (no mixing, no event emission).
- The hourly temperature step runs after action processing and before time advancement, matching the spec's update order (step 4).
- `do_sat_mg_l` uses piecewise linear interpolation with clamping at boundaries, exposed as a public function in `systems::temperature` for tests and later systems.
- Scenario materialization populates the source water catalog with ALL known presets (not just the scenario's primary source), ensuring any water change profile is available at runtime.

## Spec Deviations
- The spec lists `crates/tank_core/src/types/water.rs` for "initial-fill and water-change mixing helpers." The initial-fill helper (`WaterState::from_source_profile`) is on `WaterState`, but the water-change mixing logic lives in `systems/water_change.rs` rather than on `WaterState` directly, since it mutates the full `TankState` (not just `WaterState`).
- `dissolved_oxygen_mg_total` is not mixed during water changes. The spec's mass-balance test only checks TAN, nitrite, nitrate, phosphate, DIC, and tracked ions — DO is governed by the saturation/reaeration model and is initialized from `do_sat_mg_l(temperature)` in `from_source_profile`.
- The `SourceWaterPreset` validation (finite, non-negative) is applied at load time in `tank_data::load_source_water`. The spec's phrase "documents any derived-value tolerance" is addressed by the provenance notes on each TOML file showing the approximate GH/KH/TDS equivalents.

## Testing
- **water_change_mass_balance** (6 tests): 50% RO-like halves dissolved totals within ±0.5%, 0% is no-op, 100% yields source temperature, 50% mixes temperature proportionally, unknown profile returns `SimError::UnknownSourceProfile`, unknown profile leaves state exactly unchanged.
- **ambient_temperature_action** (5 tests): gradual warming (not instant jump), DO saturation decreases with warming, heater output zero above setpoint, heater never cools, heater fires below setpoint.
- **tank_size_thermal_response** (2 tests): 10L reaches half-delta in fewer than half the ticks of 100L, closed lid slows surface heat exchange relative to open top.
- **save_load** (3 tests): basic roundtrip, roundtrip with source water catalog + process params + heater output, save/load/resume determinism (240h + 480h = uninterrupted 720h).
- **materialization** (5 tests): nano_cycle geometry/water/substrate/plants/catalog, medium_planted dual substrate + dual plants, warm_room high ambient, deterministic materialization, unknown scenario error.
- **Existing tests**: determinism_basic, validation (2 tests), DO saturation unit tests (3 tests) — all pass unchanged.
- Total: 28 tests, 0 failures, 0 warnings.
