# Feature: Source-Water Mixing and Geometry-Driven Thermal Response

## Description
Loop 1 already completed the workspace, deterministic state/RNG/save-load foundation, geometry helper math, snapshot derivations, preset-loading scaffolding, and the minimal queued-action engine. The next missing slice is to make those scaffolds causal: resolve scenario/source-water/process presets into runtime state, execute `WaterChangePercent` with real replacement chemistry and temperature instead of pure dilution, and update water temperature hourly from ambient air, heater settings, tank size, and lid exchange. This feature should explicitly exclude feed-to-TAN conversion, hourly DO consumption/reaeration, and broader cycling behavior for now; it exists to unlock correct water-change mass balance, ambient-temperature behavior, and the thermal half of tank-size response.

## Acceptance Criteria
- [ ] `TankState` gains runtime-resolved setup data needed for deterministic continuation: a stable in-state source-water catalog keyed by preset `id`, resolved process parameters, and any thermal observables required by tests; these fields serialize in save files and schema version is bumped if compatibility is broken.
- [ ] `tank_scenarios::seeded_state` or a builder it delegates to materializes scenario presets into non-default state: scenario geometry populates `TankGeometry`, `environment.ambient_temp_c` comes from the scenario, initial `WaterState` totals come from the selected source-water profile multiplied by current fill volume, and substrate/plant state is derived from preset IDs instead of leaving `TankState::new` defaults in place.
- [ ] Source-water presets stop using GH/KH/TDS summary values as hidden source-of-truth. Each preset carries explicit per-liter values for TAN, nitrite, nitrate, phosphate, DIC, DOC, DON, alkalinity, Ca, Mg, Na, K, HCO3, Cl, SO4, and temperature; loader validation rejects non-finite or negative chemistry and documents any derived-value tolerance.
- [ ] `WaterChangePercent` removes exactly `percent / 100.0` of each tracked dissolved total, then adds replacement mass from the referenced source-water profile using exchanged liters. `0%` water changes are no-ops.
- [ ] Water changes also mix water temperature by exchanged volume. Replacing `50%` of the tank with colder or warmer source water shifts `water.temperature_c` proportionally and does not jump to source temperature unless `percent = 100`.
- [ ] Partial-failure invariant: if a queued water change references an unknown source profile or invalid resolved profile, `step_hours` returns a typed `SimError` and leaves `TankState`, queued actions, RNG state, `day`, `hour_of_day`, and `event_log` exactly unchanged. No partial mass removal, temperature mixing, or event emission is allowed.
- [ ] The hourly temperature step uses the prompt’s discrete heat model with `dt_s = 3600.0`, `heat_capacity_j_per_k = volume_l * 4186.0`, `ua_total_w_per_k = (k_surface * surface_area_m2 * top_factor) + (k_wall * wall_area_m2)`, `q_ambient_w = ua_total_w_per_k * (ambient_temp_c - water_temp_c)`, heater output only when enabled and below `setpoint_c - deadband_c / 2.0`, and `delta_temp_c = (q_ambient_w + q_heater_w) * dt_s / heat_capacity_j_per_k`.
- [ ] Existing geometry helpers drive the heat model. Smaller tanks respond faster than larger tanks, and `open_top = false` applies the existing lid multiplier to slow surface heat exchange relative to an open-top tank under the same conditions.
- [ ] `ChangeAmbientTemperature` changes only `environment.ambient_temp_c`; water temperature changes gradually on later ticks. If ambient exceeds heater setpoint, heater output eventually becomes `0.0` and never goes negative.
- [ ] A reusable `do_sat_mg_l` helper or observable is added using linear interpolation over `0 C -> 14.6`, `10 C -> 11.3`, `20 C -> 9.1`, `30 C -> 7.6`. Full DO mass updates remain out of scope for this feature, but the saturation target must be inspectable by tests and later systems.
- [ ] `ro_like` acts as the zero-nutrient reference water for regression tests: a `50%` water change using it reduces `ammonia_total_mg_n_total`, `nitrite_mg_n_total`, `nitrate_mg_n_total`, `phosphate_mg_p_total`, `dissolved_inorganic_carbon_mg_c_total`, and total tracked ions by `50% +/- 0.5%`.
- [ ] Regression coverage is added for deterministic scenario materialization, `water_change_mass_balance`, `ambient_temperature_action`, and the thermal half of tank-size response (`10 L` reaches half of its eventual ambient-step delta in fewer than half as many ticks as `100 L`). The feed-pulse TAN half of `tank_size_response` remains blocked by later nitrogen-cycle work.
