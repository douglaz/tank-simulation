# Feature: Dissolved Pool Dynamics, DO Model, pH Updates, and Event Emission

## Description
Implement the hourly dissolved-pool update systems that make water chemistry dynamic. This loop adds: (1) light-state computation, (2) reaeration driving dissolved oxygen toward saturation, (3) background biological oxygen demand from existing biomass, (4) hourly pH/alkalinity/DIC updates so pH is no longer static, (5) NH3 speciation as a runtime utility usable during simulation (not just at snapshot time), and (6) threshold-based event emission for `AmmoniaWarning`, `NitriteWarning`, and `OxygenDip`. These systems form the foundation that Milestone 4 (decomposition, nitrification, cycling) will build upon. No nitrogen-cycle transformation (TAN→NO2→NO3) or detritus decomposition is included here — those belong to Loop 4.

## Acceptance Criteria
- [ ] A helper `is_light_on(hour_of_day: u8, photoperiod_hours: f64) -> bool` exists and is used in the hourly pipeline; light is centered on noon (hour 12), so an 8-hour photoperiod means hours 8–15 are lit
- [ ] Reaeration system updates `dissolved_oxygen_mg_total` each tick: `delta_do = kLa * (do_sat - do_mg_l) * volume_l * dt_h` where `dt_h = 1.0`, `kLa` scales with `top_exchange_factor` and aeration intensity
- [ ] Background biological oxygen demand (BOD) is subtracted hourly: a small per-hour respiration draw proportional to total biomass (shrimp count, plant biomass, microbe biomass, algae biomass) so that DO can drop at night when photosynthesis is off
- [ ] During lit hours, a small net photosynthetic O2 contribution is added from existing plant + periphyton biomass (simple proportional rate, not full plant-growth model — that is Loop 5)
- [ ] DO is clamped to non-negative by the existing invariant system (no negative oxygen)
- [ ] DIC and alkalinity are nudged hourly by a small background respiration/photosynthesis delta so pH drifts realistically (respiration adds DIC; photosynthesis during lit hours removes DIC)
- [ ] pH is recomputed from alkalinity and DIC each tick using the existing `6.3 + log10(alk) - log10(dic)` formula, stored as `state.water.ph` (new field), so downstream systems can read it without recomputing
- [ ] NH3 speciation helper `compute_nh3_mg_l(tan_mg_l, ph, temp_c) -> f64` exists in a shared location and is used by both the event emitter and `TankSnapshot`
- [ ] After each hourly tick, event emission checks run:
  - `AmmoniaWarning` if `nh3_mg_l >= 0.02` (with cause `HighAmmonia`)
  - `NitriteWarning` if `nitrite_mg_l >= 0.5` (with cause `HighNitrite`)
  - `OxygenDip` if `do_mg_l < 4.0` (with cause `LowOxygen`)
  - Events are emitted at most once per day per kind to avoid log spam (track last-emitted day per kind)
- [ ] `ProcessParams` is extended with new fields: `reaeration_kla_base`, `aeration_kla_boost`, `background_bod_mg_o2_per_g_biomass_per_hour`, `plant_photosynthesis_o2_mg_per_g_per_hour`, `respiration_dic_rate_mg_c_per_g_per_hour`, `photosynthesis_dic_rate_mg_c_per_g_per_hour`
- [ ] Night oxygen dips are observable: a tank with plants and shrimp, run for 48 hours, shows lower DO at night hours than during the photoperiod
- [ ] Aeration effect is observable: with aeration enabled at high intensity, DO recovers faster toward saturation than without
- [ ] `save_load_resume` test still passes (new state fields serialize/deserialize correctly)
- [ ] `determinism_same_seed` still holds (new systems are deterministic, no thread-local RNG)
- [ ] All existing tests continue to pass
