# Implementation Response (Iteration 1)
## Changes Made
Shared DO and alkalinity limiting in `nitrogen_cycle.rs` now use sequential `do_budget` and `alk_budget` accounting across AOB, comammox, and NOB so later guilds cannot consume resources already used earlier.

Dirty-filter slowdown was added in `nitrogen_cycle.rs` via a `dirty_filter_factor` derived from `clogging_index`, combined with `maturity_factor` to reduce nitrification in clogged or immature filters.

Preset validation in `presets.rs` now rejects `comammox_vmax_fraction > 1.0`.

Three regression tests were added in `cycling.rs` to cover shared DO limiting, low-alkalinity limiting, and dirty-filter slowdown.

`Cargo.toml` was updated to enable the `serde_json` `float_roundtrip` feature to avoid 1-ULP save/load precision loss.
