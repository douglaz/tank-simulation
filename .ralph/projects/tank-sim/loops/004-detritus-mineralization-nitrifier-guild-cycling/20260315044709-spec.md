# Feature: Detritus Mineralization, Nitrifier Guild Cycling, and Biofilter Maturation

## Description
Approved loop artifacts and git history show loops 1-3 are complete: loop 1 established the workspace, deterministic state/RNG, preset loading, and save/load; loop 2 added source-water mixing plus geometry-driven thermal response; loop 3 added hourly light state, DO dynamics, pH/DIC drift, NH3 speciation, and warning events. The next missing mandatory slice is the live nitrogen cycle. Current code has detritus and microbial state placeholders, but feed still only accumulates waste and no system converts that waste into dissolved organics, TAN, nitrite, or nitrate. This feature should implement Milestone 4 only: decomposer-driven mineralization, AOB/NOB/comammox kinetics, oxygen and alkalinity coupling, seeded-vs-unseeded cycling behavior, and the feed-pulse TAN concentration response. It should explicitly defer loop-5 plant/algae growth and loop-6 shrimp reproduction/mortality work.

## Acceptance Criteria
- [ ] `Engine::step_one_hour` gains a dedicated nitrogen-cycle phase between light-state resolution and the existing chemistry/DO/event phases; within that phase the order is feed leaching, detritus breakdown/mineralization, then nitrification and guild growth/decay.
- [ ] Feed no longer creates instant dissolved nitrogen; `PlayerAction::Feed` may still add particulate mass immediately, but TAN, nitrite, and nitrate must change only through the subsequent pathway `particulate_organics_g_total -> fine_detritus_g_total -> dissolved_feed_residue_g_total` or an equivalent short-lived leach pool -> `dissolved_organic_* -> ammonia_total_mg_n_total -> nitrite_mg_n_total -> nitrate_mg_n_total`.
- [ ] Decomposition/mineralization rates are driven by `microbe.decomposer_biomass_g`, bounded environmental factors such as temperature and dissolved oxygen, and new process coefficients; rate clamps must prevent consuming more particulate, fine detritus, DOC, or DON than exists.
- [ ] `SiphonDetritus { fraction }` continues to affect only detritus pools, but it now has visible downstream cycling consequences by reducing later mineralization pressure; it must not directly remove dissolved TAN, nitrite, or nitrate.
- [ ] `ProcessParams` and the default process TOML gain the kinetic inputs needed for detritus breakdown and nitrification, including half-saturation constants, guild-specific `vmax`, growth/decay yields, a lower comammox multiplier, and any feed stoichiometry constants; preset validation rejects non-finite or negative values.
- [ ] Nitrification is split into ammonia oxidizers, nitrite oxidizers, and comammox using bounded Monod-style rates `rate = vmax * biomass * maturity_factor * f_temp * f_pH * f_do * substrate / (k_substrate + substrate)`; realized rates must be biomass-limited, oxygen-limited, slower in immature or dirty filters, and comammox must use a lower `vmax` than the TAN->nitrite path.
- [ ] Realized nitrification consumes dissolved oxygen at `4.57 mg O2` per `1 mg N` oxidized to nitrate and alkalinity at `0.1428 meq` per `1 mg N`; if TAN, nitrite, DO, or alkalinity is insufficient, only the supported fraction may convert and all coupled pools must remain finite and non-negative after the tick.
- [ ] A chemistry regression proves active nitrification lowers alkalinity and pH relative to an otherwise identical non-nitrifying control, while invariant enforcement keeps pH within `5.5..=8.5`.
- [ ] Microbial guild biomass changes over time: realized mineralization/oxidation drives growth, starvation or low-oxygen conditions drive decay, and `CleanFilter { intensity }` produces a proportional setback in active decomposer and nitrifier biomass so post-cleaning TAN/nitrite control worsens temporarily.
- [ ] A daily update hook runs every 24 hourly ticks to recompute `filter_state.biofilter_maturity_index` from current guild biomass/capacity, clamp it to `0.0..=1.0`, and emit `BiofilmMaturityIncrease` or `CycleProgressing` with non-empty `cause_codes` when maturity meaningfully improves; the existing per-day warning dedup behavior must remain intact.
- [ ] Failure-mode invariant: if any cycle sub-rate becomes non-finite or a limiter collapses to zero, that sub-rate is treated as `0.0` for the tick, unaffected substeps continue deterministically, and the tick still ends with finite non-negative dissolved pools, detritus pools, and microbial biomasses.
- [ ] `tank_scenarios` exposes a deterministic seeded/unseeded cycling fixture pair or builder so regressions can create two otherwise identical tanks that differ only in starting biofilter seeding inputs.
- [ ] `cycling_seeded_vs_unseeded` regression is added: the seeded tank reaches `tan_mg_l < 0.1` and `nitrite_mg_l < 0.1` earlier than the unseeded tank, and the unseeded tank shows non-zero TAN and nitrite peaks.
- [ ] The feed-pulse half of `tank_size_response` is added or completed: after the same feed pulse, peak `tan_mg_l` in a `10 L` tank is at least `5x` the peak in an otherwise identical `100 L` tank.
- [ ] `event_generation` regression is added or completed using a warm, overfed, weak-aeration setup; it must emit at least one of `AmmoniaWarning` or `OxygenDip` with non-empty `cause_codes`, without depending on loop-5 algae logic.
- [ ] Save/load and determinism regressions continue to pass with active cycle state, and all loop-1 through loop-3 tests remain green.
