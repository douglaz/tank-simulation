# Implementation Notes

## Decisions Made
- **Nitrogen cycle O2/alkalinity coupling handled inline**: Rather than passing coupling values from `nitrogen_cycle.rs` back through `dissolved_oxygen.rs` and `chemistry.rs`, nitrification's O2 consumption and alkalinity depletion are applied directly within the nitrogen cycle step. This avoids double-counting and keeps the coupling tightly co-located with the reaction that produces it. The existing DO and chemistry steps continue to handle background respiration, reaeration, and DIC-driven pH independently.
- **AOB/NOB O2 split**: The 4.57 mg O2 per mg N demand is split between AOB (3.43 mg O2 for TAN→NO2) and NOB (1.14 mg O2 for NO2→NO3), with comammox using the full 4.57 for TAN→NO3. Each step checks remaining DO before proceeding.
- **Environmental factors**: Temperature factor uses a Gaussian bell curve peaking at 28°C (σ=10°C). pH factor uses a similar Gaussian peaking at 7.5 (σ=1.5). These are biologically reasonable simplified curves for v1.
- **Maturity factor gates nitrification**: `filter_state.biofilter_maturity_index` is used directly as a multiplier on all nitrifier Monod rates, clamped to [0.05, 1.0]. This ensures immature filters slow nitrification as specified.
- **Daily biofilter maturity update**: Uses an exponential moving average (α=0.1) toward a raw maturity derived from total nitrifier biomass relative to a 0.5g capacity reference. Emits `BiofilmMaturityIncrease` and `CycleProgressing` events when maturity meaningfully increases.
- **Feed pathway**: `PlayerAction::Feed` adds to `particulate_organics_g_total` only (no instant dissolved nitrogen). The pathway is: particulate → fine_detritus (leach rate/hour) → DOC/DON (dissolution rate/hour) → TAN (decomposer mineralization) → NO2 (AOB) → NO3 (NOB), with comammox shortcutting TAN→NO3.
- **Decomposer biomass in cycling fixtures**: Both seeded and unseeded fixtures share the same decomposer biomass (0.1g) so that TAN generation rates are equal; they differ only in nitrifier biomass and maturity, isolating the cycling variable.
- **ProcessParams extended with serde(default)**: All new fields in `ProcessParamsPreset` use `#[serde(default)]` so existing TOML files without the new fields still load correctly.
- **CleanFilter biomass setback**: Intensity-proportional setback (50% of intensity) applied to all four microbial guild biomasses (decomposer, AOB, NOB, comammox).

## Spec Deviations
- **`dissolved_feed_residue_g_total` is bookkeeping only**: The spec mentions an "equivalent short-lived leach pool" — we use `dissolved_feed_residue_g_total` to track flow through the dissolution stage but the actual dissolved state is in `dissolved_organic_carbon_mg_c_total` and `dissolved_organic_nitrogen_mg_n_total`. The residue field tracks cumulative throughput and is decremented when mineralization consumes DOC/DON.
- **Comammox uses AOB's vmax × fraction rather than a separate vmax field**: The spec says "lower vmax" — we implement this as `aob_vmax * comammox_vmax_fraction` (default 0.4) rather than an independent absolute vmax, which is functionally equivalent and reduces parameter count.
- **`emit_once_per_day_pub` wrapper**: To reuse the private `emit_once_per_day` dedup logic from the daily update hook in `engine.rs`, a thin public wrapper was added to `events.rs`. This preserves the existing dedup behavior intact.

## Testing
- **`cycling_seeded_vs_unseeded`**: Seeded tank reaches low TAN/nitrite faster than unseeded. Unseeded shows non-zero TAN and nitrite peaks.
- **`filter_cleaning_setback`**: Verifies AOB/NOB biomass decreases after filter cleaning, and TAN rises when feeding resumes.
- **`limiter_correctness_no_negative_pools`**: Extreme scenario (50g feed, zero DO, zero microbes) — all pools remain finite and non-negative after 100 hours.
- **`siphon_detritus_reduces_cycling_pressure`**: Siphoning reduces particulate detritus without directly removing dissolved TAN/nitrite/nitrate.
- **`nitrification_lowers_alkalinity_and_ph`**: Active nitrification produces lower alkalinity and pH than an identical non-nitrifying control, with pH remaining in [5.5, 8.5].
- **`feed_pulse_tan_concentration_scales_with_volume`**: Peak TAN mg/L in 10L is ≥5× the 100L peak after the same feed pulse.
- **`event_generation_warm_overfed_weak_aeration`**: Warm (30°C), overfed (3g/day × 14 days), weak-aeration tank emits AmmoniaWarning or OxygenDip with non-empty cause_codes.
- **`save_load_with_active_cycle_state`**: Save/load determinism verified with active microbe and filter state.
- **`cycling_fixtures_are_deterministic_and_differ_in_seeding`**: Fixtures are deterministic with same seed, differ only in microbe/filter state.
- **All 48 tests pass** including all loop-1 through loop-3 regressions (determinism, save/load resume, water change mass balance, thermal response, ambient temperature, dissolved oxygen, chemistry pH drift, threshold events).
