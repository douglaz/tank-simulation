# Implementation Response (Iteration 1)

Only completed cohorts resolve; newly berried females start at progress 0 in a separate cohort. `berried_females_count` and `egg_progress_days` update only for resolved clutches. Legacy save compatibility is handled via a migration path.

2. **`thermal_reproduction_penalty` test**: Extended the test to run for 60 days instead of 20. It now asserts at least 20% lower readiness and strictly fewer juveniles in the 30°C tank. The scenario uses a large, well-maintained tank with controlled spawn rate to isolate the thermal effect.
